# Real data: Chen et al. (2024)

Tools to export the public Neuropixels recordings of Chen et al. (2024), *Brain-wide neural activity underlying memory-guided movement* (Cell 187, 676–691), in an HDF5 layout the benchmarked models can be fit to. The recordings are on DANDI as [dandiset 000363](https://dandiarchive.org/dandiset/000363).

> This repository does not contain, own or claim rights to the recordings. It only reads the public files on DANDI. Please cite Chen et al. (2024) and the DANDI archive when you use the data.

The code is in `src/chen2024/`, the command-line scripts in `scripts/chen2024/`, and the configurations in `configs/real_data/chen2024/`. Settings are described in the [configuration reference](chen2024_config_reference.md).

## Setup

```bash
pip install -r requirements.txt
```

`pynwb` reads the NWB files.

**Data version.** The scripts use version **0.230808.2053** of dandiset 000363 by default, the version the benchmark's real-data datasets are built from (see “Dandiset versions” below). Its session files are about 220 MB each.

## 1) Download sessions

List the subjects, or one subject's sessions and their sizes, without downloading anything; then download:

```bash
python scripts/chen2024/download.py --list-subjects
python scripts/chen2024/download.py --subject 440959
python scripts/chen2024/download.py --subject 440959 --download --output raw
```

[`notebooks/explore_chen2024.ipynb`](../notebooks/explore_chen2024.ipynb) summarizes the downloaded files: sessions, units per area, good-unit fractions and firing rates. `scripts/chen2024/inspect_nwb.py --input raw` prints each file's trial and unit columns.

## 2) Convert to HDF5

```bash
python scripts/chen2024/preprocess.py --config configs/real_data/chen2024/example_440959.yaml --input raw --output processed_440959
```

The conversion can also stream a session from DANDI without downloading it (`--dandi-subject 440959 --dandi-session 20190225T142613` in place of `--input`; needs `pip install remfile`). This is only worth it for the latest version, whose files are 250–400 GB.

## 3) Check the output

```bash
python scripts/chen2024/validate.py --input processed_440959
```

## Dandiset versions

The curation of the units changed between versions of dandiset 000363, so the same session can give a different set of units. Spike times are the same in every version that has them.

| Version | Session files | Units |
| --- | --- | --- |
| 0.221127.2345 to 0.230214.1833 | under 300 MB | no `anno_name` or `classification` columns, so they can't be converted |
| 0.230613.1608, **0.230808.2053 (default)** | about 220–280 MB | first curation |
| 0.230822.0128 | about 220 MB | revised curation: some units change `classification` or lose their `anno_name`, others become `good` |
| 0.231012.2129 (latest) | 250–400 GB (adds raw voltage and video) | same units as 0.230822.0128 |

For subject 440959's session of Feb 25, 2019, for example, the first curation gives 368 good, labelled units and the revised one 391. Another version can be chosen with `download.py --version` or `preprocess.py --dandi-version`. Streamed output records the version in the session attribute `source_dandiset_version`.

## What the conversion does

- **Trials.** Keeps trials whose duration is within 5.0 ± 0.5 s and, by default, drops photostimulation trials (a trial is unstimulated only if `photostim_onset` is exactly `"N/A"`). Only accepted trials are written; `source_trial_row` gives each one's row in the NWB trial table.
- **Units.** Keeps units with `classification == "good"` (configurable).
- **Areas.** Translates each unit's Allen CCF structure name (`anno_name`, such as "Secondary motor area, layer 5") to its abbreviation (`MOs5`), using the table in `src/chen2024/data/`. The `regions:` block of a configuration groups abbreviations into output areas (for example `ALM: [MOs2/3, MOs5, MOs6a]`), stacking each group’s units area by area in the order listed; an empty `regions: {}` writes one dataset per abbreviation. `example_440959.yaml` gives the five areas the benchmarked models are fit to: ALM, Thalamus_ALM, Thalamus_other, MRN_PPN and SC.
- **Binning.** 500 equal bins per trial, from trial start to trial stop, so a bin is about 10 ms (each trial's bin width is stored).

## Output format

One file per subject, `sub-{subject}/sub-{subject}.h5`, with one group per session, `ses-{session}` (for example `ses-20190225T142613`). In each session:

| Name | Contents |
| --- | --- |
| `area-{name}` | Spike counts, int32, shape (trials, units, time bins). `/` in a name becomes `_` (`area-MOs2_3`). |
| `unit_metadata/{name}/` | Per unit: `unit_id`, `anno_name` and `source_unit_row` (row in the NWB units table). |
| `source_trial_row` | Row of each written trial in the NWB trial table. |
| `start_time`, `stop_time`, `trial_duration_s`, `bin_width_s` | Trial timing, in seconds. |
| `photostim_onset`, `outcome`, `trial_instruction`, ... | The trial columns listed under `metadata.trial_fields`. |
| `subject_id`, `subject_name`, `session_id` | Identifiers. |

Every `area-*` dataset has attribute `type = "data"` and every trial or identifier dataset `type = "info"`. The session group's attributes record the source file, the dandiset, the number of bins, the accepted trial count and the full configuration (`config_json`).

Unlike the simulated datasets, these files hold every accepted trial of a session in one group and put units before time. Splitting into training, validation and test trials, and choosing held-out neurons, is left to the user.
